# 异地训练：先看这一页

你要做的事只有一件：**打开笔记本，从上往下跑完**。

目标是让这台机器替本机跑一次模型训练，然后把结果发回来。你**不需要**懂模型、
**不需要**装包、**不需要**设环境变量、**不要**改包里或工具里的任何文件。
所有细节都已经钉死在脚本里了。

---

## 一、上传（只做一次）

在这台服务器的 Jupyter 里，建一个工作目录（用文件浏览器左边的 `Upload` 就行），
把**两样东西**放进去：

1. `attest/` 这个文件夹（整个文件夹，连同里面的 `ATTEST.ipynb`）
2. 本机发来的训练包 `.zip`（**不要**自己解压，笔记本会自动解）

放好之后目录看起来像这样：

```
工作目录/
├── attest/
│   ├── ATTEST.ipynb     <- 你双击打开这个
│   ├── pt.py
│   ├── pt_config.json
│   └── scripts/ ...
└── 训练包zip（比如 S03_alphalgbm_csi800.zip）
```

> 如果本机已经把包解压好了，那就把解压出来的那个目录（里面有 `MANIFEST.json`）
> 放在同一层，效果一样。压缩包和解压目录**只留一个**，不要两样都在，
> 否则笔记本会问你用哪个。

## 二、跑笔记本

双击打开 `ATTEST.ipynb`，然后菜单里选 `Kernel -> Restart & Run All`，
或者一格一格按 `Shift+Enter` 往下跑。笔记本一共 9 节，每节开头都写了在做什么：

| 节 | 做什么 | 要不要你动手 |
|---|---|---|
| 1 | 配置 | 通常一个字都不用改 |
| 2 | 装载 | 直接跑 |
| 3 | 找到包 | 只有提示"多个候选"时才要你填 |
| 4 | 体检 | 直接跑，**不通过就停** |
| 5 | 冒烟（CPU，不产模型） | 直接跑 |
| 6 | 真训练（要 GPU） | 要真训，先把 `DO_REAL_TRAIN` 改 `True` |
| 7 | 超参搜索（通常跳过） | 只有本机随包发了网格才做；默认只打计划，不真跑 |
| 8 | 评估与裁决 | 直接跑，只产报告 |
| 9 | 打包回传 | 直接跑 |

**你唯一需要动手改的是第 1 节**，而且通常一个字都不用改：

- 多数情况 `BUNDLE` 留空就行，笔记本会自己找到那个包。
- 只有屏幕上提示"有多个候选"时，才需要把 `BUNDLE` 填成你要训的那个目录名。
- `DO_REAL_TRAIN` 默认是 `False`，**先别动**。第一次请让它保持 `False` 跑一遍，
  确认体检和冒烟都过了，再回来改成 `True` 做真训练。

第 1 节一共 5 个开关（`BUNDLE` / `WORK_DIR` / `DO_REAL_TRAIN` / `DO_SEARCH` /
`WITH_MODELS`），默认值都是最保守的那一档。**本机没在交付说明里点名让你改哪一个，
就一个都别动**。`GATE_OK` / `DOCTOR_VERDICT` 是工具自己写的状态，你不要手改。

### 第 7 节（搜索）大概率是跳过的

搜索这一节只有在本机**随包发来一份网格**时才有事做。屏幕上出现
「本包没有随包网格，跳过这一节」，那是**正常跳过**，不是出错，继续往下跑就行。

真要跑搜索时它也很贵：训练次数 = 格子数 × 种子数 + 1。所以这一节**总是先打一个计划**
给你看（要跑几次、大概多久），再问要不要真跑 —— 第 1 节的 `DO_SEARCH` 默认是 `False`。
本机没在交付说明里明确让你打开它，就保持 `False`，只把计划发回本机。

**不要**自己写一份网格、也不要改随包发来的那份。写错的后果不是报错，
而是一张每格数字都一样的表 —— 那看起来像结论，其实什么都没扫到。

## 三、三个判断，看屏幕上的总判

第 4 节体检跑完会打印一行 `体检总判：`，只有三种情况：

- `通过` 或 `注意` -> 继续往下跑。
- `不通过` -> **停下来**，不要往下跑。把 `!!!!` 方框里的内容发回本机。
- `判不了` -> 也**停下来**。`判不了`是**没检查到**的意思，**不等于通过**。
  把那几条读完，确认没问题之后，回到第 1 节把 `I_READ_THE_UNKNOWNS` 改成 `True`，
  再重跑第 4 节。

> 注意：Jupyter 的 `Run All` **不会**因为某一格报错就停下，它会继续往下跑。
> 所以后面每一节都会**自己再检查一次闸门**：体检没过时，它们会拒绝执行并各自报错。
> 看到 `体检没有通过，本格拒绝执行` 就说明闸门在起作用，这是正常的，不是坏了。

第 8 节评估跑完会打印一行 `裁决姿态：`，那是本机要看的结论，你**不用**去解读它，
也不用据此做任何决定，原样发回就行。它可能是 `not-ready`、`blocked` 等，都不是让你去处理的。

## 四、发回去

最后一节（第 9 节）会生成一个 zip，名字里带着**这一轮的结论**，
例如 `pt_backup_S03_alphalgbm_csi800_UNKNOWN_20260917_134117.zip`。
名字中间那个词：跑到第 8 节评估了，它就是评估结论；没跑到，就是体检结论 ——
屏幕上会有一行 `体检/裁决 : ...` 告诉你它是从哪一份读出来的，照抄给本机就行。
在左边文件列表里找到它，**和同名的那个 `.sha256` 文件**一起右键 `Download`，发给本机。

里面有体检报告、训练指纹、日志，以及第 8 节产出的 `report.md` 与 `eval.json`。
`report.md` 是给人读的：结论在最前面，依据在后面，**判不了的项单列一节**。
包里还有一份 `COLLECT.json`，逐件写明"哪些大件没带、为什么没带"——**那不是丢件**。
模型权重默认不在里面（回传体积大且搜索场景用不上）；本机要的话会在交付说明里
让你把第 1 节的 `WITH_MODELS` 改成 `True` 再重跑第 9 节，不用你自己判断该不该带。

这个包**无论前面成没成功都会生成**——体检没过时，里面装的至少是体检报告，
那正是本机需要看到的东西。所以哪怕前面红了，也请把最后一节跑完。

**不要**自己判断结果好不好、不要自己挑模型、不要往任何生产目录里覆盖东西、
**不要改报告里的任何数字**。裁决由本机做，上线由哥独断。

## 附：这台机器如果也有终端

有终端的话可以不开笔记本，直接敲命令，与笔记本各节一一对应：

```
python pt.py doctor --bundle <包目录> --out <空目录>                       # 体检
python pt.py train  --bundle <包目录> --mode smoke --out <空目录>          # 冒烟，CPU
python pt.py train  --bundle <包目录> --mode week --commit --out <空目录>  # 真训练，要 GPU
python pt.py search --bundle <包目录> --out <空目录>                       # 搜索计划，不训练
python pt.py search --bundle <包目录> --out <空目录> --commit              # 真搜索，要 GPU
python pt.py eval   --bundle <包目录> --workdir <空目录>                   # 评估，只产报告
```

`--commit` 是必须的，少了它工具会拒绝执行，这是防误触发的。
真训练默认用 **10** 个随机种子各跑一次，用来估计噪声底——同一份数据换个种子结果本来就会变，
没有这个底数就无法判断"改进"是不是真的。少了它，评估会明确给你一个「判不了」，
而不是假装通过。10 个种子意味着训练时长约为 1 个种子的 10 倍，这是**有意**的：
底数不厚就分不清"改进"与"换个种子"。

> 上面那条命令想快一点（比如只是先试通链路），可以在末尾加 `--seeds 1,2,3`，
> 明确跑少几个种子。**不要**自己改 `pt_config.json` 里的数字。

搜索那两条命令**不用给 `--grid`**：网格由本机随包发来，工具自己会在包里找。
包里没有网格时它会停下来并说明去向本机要 —— 这种时候不要去编一份。

回传就是第五个动词（与笔记本第 9 节做的是同一件事）：

```
python pt.py collect --workdir <空目录> --out .        # 打包回传，只产 zip，不写别处
```

它会生成一个 `pt_backup_<包名>_<结论>_<时间>.zip` 和一个同名的 `.sha256`，
**两个一起发回本机**。默认不带模型权重（搜索场景不需要）；如果本机明确说要带，
加 `--with-models`。哪些没带、为什么没带，它会在 `COLLECT.json` 里逐件列明，不会悄悄丢。

## 出问题时

屏幕上任何 `!!!!` 开头的方框都是说给你看的，里面有四段：
**发生了什么 / 为什么是问题 / 下一步做什么 / 找谁**。照着做，并把原文发回去。

日志在 `_pt_work/logs/` 下，每个试次一个 `.log`。

不确定的事**不要猜**，也不要把"判不了"当成"通过"。
