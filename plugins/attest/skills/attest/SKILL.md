# attest

薄壳。真正的口径在代码里，**不要凭记忆复述参数**——先看 `README_FIRST.md`（给异地操作者）
与各脚本的头部 docstring（给本机）。盘符不假设：所有根目录走
`pt_config.json` -> 环境变量 `PT_*` -> 命令行 三级覆盖，换机器只改配置文件。

## 一句话分工

| 侧 | 谁 | 做什么 |
|---|---|---|
| 本机 | 我 / 哥 | `pt_pack.py pack` 打包发出（**搜索网格随包一起装进去**）；`export_to_z.py` 把 D 的三件套映射回 Z 并闸住半拉子；看回传报告后由**哥**裁决 promote |
| 异地 | 不懂细节的操作者 | 开 `ATTEST.ipynb`（或敲 `pt.py` 五个动词），从头跑到尾，把 zip 发回 |

为什么 `pack` 不放进 `pt.py` 的五个动词里 —— 那五个是异地操作者的动作；`pack` 是本机侧的，
混进去会让异地那页文档说不清。要跑就直接 `python scripts/pt_pack.py pack --help`。

## 异地那台机器：五个动词

```
doctor  ->  train --mode smoke  ->  train --mode week --commit  ->  eval  ->  collect
体检        冒烟（CPU，不产模型）      真周训（要 GPU，默认 10 seed）   裁决      回传
                                          \->  search --commit  （可选分支：要扫超参时走它）
```

- **`doctor` 不通过就停**。三种总判：`通过`/`注意` 继续；`不通过` 停；`判不了` 也停——
  `判不了` 是"没检查到"，**不是通过**。这条是全套防呆里最容易被人绕过去的一条。
- `train` 默认 dry-run，**必须 `--commit`** 才写盘。
- `collect` 默认不带模型权重（搜索场景只要指标），`--with-models` 才带；
  没带的逐件列在 `COLLECT.json` 的 `skipped` 里，不是丢失。

## 超参搜索（search）的四条纪律

**网格随包走，不让异地自己编。** 该扫哪些键取决于**这个包的入口怎么写**——这是本机才知道的
事。本机 `pack --grid` 时装进包里（`SEARCH_GRID.json`），打包前按**这个包**验一遍，
扫不动的键当场拦下、zip 不生成。异地 `pt.py search` 不用给 `--grid`；包里没有就停下并说明
去向本机要。**为什么宁可拦在打包这一步**：扫一个没接上的键不会报错，它只会给出一张
每格数字都一样的表 —— 看起来像结论，其实什么都没扫到，比没有结果更坏。

**不报"最高分参数"。** 目标只允许 `cand_val_ic`（val 窗）。`S03` 的门禁判据本身是拿
**test 窗**裁决的（`ct >= lt and ct > 0`），拿它当搜索目标就是直接拟合判据。所以报的是
**邻域稳定区**：按容差把"彼此差不多好"的格子连成一片，取最大连通块，
推荐值是**区域中心**而不是峰值格。峰值只记录，不作推荐。

**容差要有出处。** 优先用同格内多种子的合并标准差（实测），次取 `fingerprint.json` 的噪声底，
都没有才退回工具写死的兜底值 —— 三种来源都写进 `region.json`，不许只给一个数字。

**强制 holdout，且它有否决权。** 搜索全程看不见 train 窗末尾切出的那几天；
跑完用推荐参数在上面训一次，与**同窗的现役模型**比（`cand_val_ic` vs `live_val_ic`）。
不达标就是 `region-holdout-failed`：这时 `recommendation.emit` 为 false、`params_usable` 为 false，
**那组参数一律不许当推荐用**——下游只看 `emit` 的人不会误用它。

搜索产物固定三件：`surface.csv` / `region.json` / `trials.csv`。`collect` 认这三件；
没跑搜索时它们不该被列成"缺"（那是本来就不该有），跑了才逐件核对齐全与否。

## 本机侧：发一个包

```
python scripts/pt_pack.py pack --bundle <Z包目录> --out <本地目录> [--no-models]
```

产出 `<包名>_<锚点>_<时间戳>.zip` + 同名 `.sha256`，zip 里顶层就是包名目录、
含 `DISPATCH.json`（**X/Y 的 sha1 是实算的**，MANIFEST 的声明值并排留档）。

打包前的自检会**硬拦**两种情况，缺一不可地看一眼：

1. `MANIFEST.anchor_date` 与 `Y/Y_meta.json` 的锚点不是同一天 —— 半拉子刷新，
   这种包发出去异地无从归因，事后复现不了；
2. 声明 sha1 与实算不符 —— 账物不符。

这是**包内自洽性**检查。本工具**不报**"某 Z 包与他机 D 包不一致"这类结论：
本机只负责 `D六件套 -> 本机生成 -> Z对应三件套` 这一条链，Z 上他机写的包由他机对齐。

## 本机侧：Z 的锚点闸

```
python //192.168.3.33/Data/Ongoing/_tools/export_to_z.py check [-v] [--only <包名>]
```

四桶，**不许把 `判不了` 读成 `通过`**：`不通过`（硬矛盾）/ `判不了`（契约字段缺失）/
`注意` / `注记`（设计如此：无 sha1 的非 npy 件、本就不是三件套的包）。
只有 `不通过` 会影响退出码。

- `plan` 只读预览；`apply` 默认 dry-run，`--apply` 才写且带时间戳备份；
- `close-out` 调**包自己**的 z_sync 生产线重建，默认只打印命令，`--apply` 才跑；
- 合并规则：Z 为底，D 的数据键覆盖，但 `anchor_date`/`anchor_raw`/`exported_at` 与
  所有 Z 同步期键**绝不取自 D**，并置 `pending_close_out`。
  只改"别让 D 盖 Z 的锚"是**错的**——那会把必然的 FAIL 变成行数不变时看不见的谎。

## 硬边界（不要越）

- **不改任何策略包**、不改 `_sync/make_train_from_xy_*.py` 生成器、不改 `D:\ZML\trading\*`。
- **不写 Z**，除非哥指名 + 具体路径授权；往 Z 落产物一律用 UNC（`//192.168.3.33/Data`），
  不用映射盘 `Z:`（慢约 40 倍）。
- 母本守卫：目标落在 `master_roots` 之下拒绝写入（退出码 4），除非显式 `--allow-master-write`。
- 异地"闭环"只到**给出裁决结论**为止；**promote 只在本机、且哥独断**。
- 不落 `__pycache__`（Z 侧铁律，本工具自己也守）。
- 口令类东西绝不写进包里任何文件；取不到就当场报错，不许静默用空值往下跑。

## 回传回来先看什么

`report.md` 结论在前、依据在后、**判不了的项单列一节**；机器可读是 `eval.json`。
裁决姿态（`decision-grade` / `review-ready` / `screen-grade` / `not-ready` / `blocked`）
由输入状态读出，**不从前一状态升降**。候选相对基线的增量没超出多 seed 噪声底时判
`UNKNOWN`，不判 PASS。最后 promote 与否，把材料摆给哥，由哥定。

**逐日配对检验**（`ic_series.json` 在场时）：同一天上候选与现役作差消掉市场公共项，
再做循环分块自举。三种情形分开说：文件不在 → `注意`（是工具/训练侧的方法局限，
不是包的缺陷）；文件在但契约不符 → `不通过`；文件在且合规 → 真做，结论可以是"不显著"
（记 `判不了`）。**"不显著"永远不许读成"没改进"**，也不许读成"通过"。
配对 t 与分块自举结论不一致时取保守口径：`判不了`。
